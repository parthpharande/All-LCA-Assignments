# LCA1 - Python Assignments

This repository contains solutions to the LCA1 Python assignments.

`assignment1.py`  Student Data Management using Dictionary, Tuple, and List 
`assignment2.py`  Find the largest of three numbers 
`assignment3.py`  Check if a triangle is right-angled (using a function) 
`assignment4.py`  Addition of two matrices 
`assignment5.py`  PAN number validation using regular expressions 

## How to run

Each file is standalone. Run any of them with:

```bash
python assignment1.py
```

(replace `assignment1.py` with the file you want to run)
